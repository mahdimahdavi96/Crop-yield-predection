# Crop-Yield-Prediction

This repository provides machine learning and deep learning models for crop yield prediction in semi-arid and humid regions. Predicting crop yields is inherently complex due to various interacting factors such as crop genotype, environmental conditions, and their correlations.

## Overview

This research leverages a deep learning framework that integrates **Convolutional Neural Networks (CNNs)** and **Recurrent Neural Networks (RNNs)** to forecast crop yields using historical weather and soil data. The model’s performance is evaluated against traditional machine learning methods including:

- **Random Forest (RF)**
- **Support Vector Machine (SVM)**
- **Least Absolute Shrinkage and Selection Operator (LASSO)**

## Data

The study uses historical yield data spanning **1990–2023** for:
- **Wheat** in Arizona and Kansas  
- **Cotton** in Arizona and Georgia  

## Key Findings

- The **CNN-RNN model** consistently outperforms traditional methods, achieving significantly lower **Root Mean Square Error (RMSE)**.
- The model shows robust predictive accuracy across different climate zones, particularly in semi-arid regions like **Arizona** and humid regions like **Georgia** and **Kansas**.
- A comparative analysis highlights how **weather and soil variability** impact crop yields differently in diverse regions, offering insights for adaptive crop management.

## Purpose

This work aims to support data-driven agricultural planning and sustainable farming by providing accurate yield forecasts tailored to regional climate conditions.

## Applications

- Precision agriculture
- Crop planning and rotation strategies
- Agricultural risk assessment under climate variability
